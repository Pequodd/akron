# АКРОН: корпоративный сайт (концепт)

Концепт корпоративного сайта вымышленной архитектурно-строительной компании, которая строит каменные загородные дома под ключ в Московской области. Это проект для портфолио: компания, проекты, цены и цифры придуманы.

## Страницы

| Файл | Что на странице |
|---|---|
| `index.html` | Главная: знак, вырезанный из фото, о компании, проекты, этапы стройки, комплектации, построенные дома, заявка |
| `projects.html` | Каталог проектов с фильтрами по этажности, площади и стилю |
| `project.html#ladoga` | Карточка проекта: характеристики, схема планировки по этажам, интерьеры, калькулятор комплектации |
| `objects.html` | Построенные дома |
| `technology.html` | Разрез стены с интерактивными слоями, принципы, фундамент и кровля, гарантия |
| `about.html` | Позиция, отделы, история, компания в цифрах |
| `contacts.html` | Телефон и почта с копированием, схема проезда, заявка |

Проекты и объекты лежат в `assets/js/data.js`: страницы каталога, карточек и планировок собираются из этих данных.

## Запуск

Сайт статический, сборка не нужна:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Дизайн

- Шрифт: Jost (Google Fonts), тонкое начертание для заголовков и обычное для текста.
- Палитра: минеральный белый `#F5F6F2`, графит `#1C2420`, хвойный `#1F3A2D`, шалфей `#E3E8DF`.
- Главный приём: шторка на первом экране сравнивает эскиз проекта (`hero-sketch.jpg`, сделан из фото) с построенным домом.
